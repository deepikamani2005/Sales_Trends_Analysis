# Sales_Trends_Analysis

This project analyzes sales data using Power BI to identify sales trends, revenue patterns, popular products, payment methods, and purchase types. An interactive dashboard is created to visualize key sales metrics and support data-driven business decisions.

Tools Used: Power BI, Excel

Dashboard Insights:
Total Sales and Quantity
Sales Trends Over Time
Sales by Payment Method
Sales by Purchase Type
Sales by Product
Orders by City
